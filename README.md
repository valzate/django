## Descripción del Proyecto

Este proyecto consiste en una aplicación que muestra una página con un catalogo de productos que extrae desde un archivo JSON. Este trabajo fue realizado con el lenguaje Python para su funcionalidad,
con un archivo en cargado de gestionar las rutas a donde y de donde se debía enviar la información, otro archivo con el que inicia la aplicación y un ultimo que corre la aplicación. Su estructura y
su estilo están escritos en HTML y CSS.
